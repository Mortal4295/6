One Node server that serves OpenAI- and Anthropic-compatible chat requests by routing each one to the best free model across ten simulated providers, speaking each provider's own wire and failing over on refusal. It reads the trial brief, probes every provider's catalog, and answers in the wire the client used.

## Run it

```sh
node main.ts
```
